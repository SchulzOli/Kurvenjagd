# Verhaltenskodex

Wir wollen, dass sich alle in diesem Projekt willkommen fühlen – unabhängig von Alter, Körper, Behinderung, Herkunft, Geschlecht und geschlechtlicher Identität, Erfahrung, Nationalität, Aussehen, Religion oder sexueller Orientierung. Und unabhängig davon, welches Motorrad jemand fährt.

## Das erwarten wir

- Freundlich und respektvoll bleiben, auch bei Meinungsverschiedenheiten.
- Kritik an Ideen und Code üben, nicht an Personen.
- Neue Leute unterstützen; jede Frage ist erlaubt.
- Verantwortung für Fehler übernehmen und daraus lernen.

## Das geht nicht

- Beleidigungen, Belästigung, Drohungen, sexualisierte Sprache oder Bilder.
- Persönliche Angriffe, abwertende Kommentare, Trollen.
- Private Daten anderer veröffentlichen.
- Aufrufe zu gefährlichem oder rechtswidrigem Fahren (Rennen auf öffentlichen Straßen, Blitzer-Warnungen o. Ä.).

## Durchsetzung

Verstöße bitte an die Maintainer melden – über die Meldefunktion von GitHub (bei Beiträgen „Report content“) oder vertraulich über einen [Sicherheitshinweis](SECURITY.md). Meldungen werden vertraulich behandelt. Die Maintainer können Beiträge entfernen, verwarnen oder Personen vom Projekt ausschließen.

Dieser Kodex orientiert sich am [Contributor Covenant 2.1](https://www.contributor-covenant.org/de/version/2/1/code_of_conduct/), dessen ausführliche Fassung ergänzend gilt.
